ZabiyakaPr0b1v — установка как приложение (PWA)

ВАЖНО: для настоящей установки PWA сайт должен открываться по HTTPS (или localhost).
Один HTML-файл, открытый как file://, обычно нельзя установить как полноценное приложение.

Файлы:
- index.html — приложение
- manifest.webmanifest — имя, иконки и режим standalone
- sw.js — сервис-воркер для базового офлайн-кэша оболочки
- icon-*.png — иконки приложения

Как установить на Android:
1. Разместите содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Откройте HTTPS-адрес в Chrome на Android.
3. Нажмите меню ⋮ → «Установить приложение» или «Добавить на главный экран».
4. Подтвердите установку.

Сетевые сведения по IP загружаются с ipwho.is, поэтому для самого анализа нужен интернет.
